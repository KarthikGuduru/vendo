# Sorted

Pitch site for Sorted, an office vending machine that only stocks
Trustified-certified, zero-sugar and high-protein snacks. Built with the
scroll-craft skill.

- `site/` is the whole website (static HTML, CSS, JS, images). Netlify
  publishes this folder; there is no build step.
- `BRIEF.md` is the design brief. It is not published.

Local preview: `npx serve site` (or any static server), then open the URL.

Set the inbox for the "Get a machine" button in `CONTACT_EMAIL` near the top of
the script in `site/index.html`.
